# 📦 Supply Chain Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Supply Chain Analytics Dashboard** built using **Microsoft Power BI**. The objective is to analyze supply chain operations, product performance, customer demographics, supplier efficiency, manufacturing costs, and logistics performance to support data-driven business decisions.

The dashboard enables stakeholders to monitor operational KPIs, identify improvement opportunities, and evaluate product and supplier performance through interactive visualizations.

---

## 🎯 Business Problem

Organizations managing supply chains often face challenges such as:

- Inefficient inventory management
- High logistics and manufacturing costs
- Supplier performance evaluation
- Product quality monitoring
- Customer demand analysis

The goal of this project is to transform raw operational data into meaningful insights that help management improve efficiency, reduce costs, and optimize decision-making.
